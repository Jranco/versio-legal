## What Versio does

Versio reads design token, variable, and style data from the Figma file you run it in; builds versioned snapshots of that data; computes differences between snapshots; and suggests a semantic version bump (major/minor/patch) based on those differences. It can optionally push a snapshot to a GitHub Gist you configure yourself.
